# MiBolsillo — Canal Oficial de Actualizaciones (OTA)

Repositorio oficial para la distribución de instaladores APK y notas de versión de **MiBolsillo**.

Este repositorio funciona como el canal de actualizaciones automáticas (OTA) integrado directamente dentro de la aplicación en **Más → Actualizaciones**.
